## 4. Findings

1. **TypeScript 7 works with Next.js 16.** D-020's note "use the version Next.js supports" is answered: 7.0.2 builds and type-checks.
2. **Node 22.14.0 is enough** for Next 16.4.5 (needs >=20.9) and ESLint 10 (needs ^22.13).
3. **psycopg is LGPL-3.0.** It is OSI-approved weak copyleft, used unmodified through dynamic import. Accepted and recorded in the licence register.
4. **API image is 1.99 GB.** spaCy (128 MB, pulled in by Presidio), phonenumbers, numpy and botocore are the largest packages. Not a blocker. Revisit in T1.03 with a multi-stage build.
5. **Keycloak images on quay.io and uv images on ghcr.io could not be pulled from this container** because of its network policy. Keycloak's Docker Hub image was used. This is an environment limit, not a project finding. The Dockerfile installs uv from PyPI so it does not need ghcr.io.
6. **Presidio analyzer was not exercised**, because it needs a spaCy model download. T0.04 covers it.
